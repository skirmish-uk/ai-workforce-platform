# Pricing and Packaging

## Positioning

Do not sell tokens.

Do not sell model access.

Do not sell "prompts."

Sell:
- tailored AI employee
- managed operation
- integrations
- outcomes
- ongoing improvement
- support
- security

## Suggested initial commercial structure

### Setup
Configurable implementation fee.

Includes:
- discovery
- workflow mapping
- knowledge setup
- integrations
- agent configuration
- testing
- deployment

### Monthly
Configurable subscription.

Includes:
- agent operation
- hosting/runtime
- model usage within internal limits
- monitoring
- maintenance
- support
- improvement requests
- reporting

### Potential tiers

Starter:
- 1 core agent
- limited workflows
- standard integrations

Growth:
- multiple agents
- more workflows
- custom integrations
- advanced monitoring

Managed AI Operations:
- highly tailored agent workforce
- multiple workflows
- priority support
- advanced security
- operator-managed improvements

Do not finalise prices in code. Store plans/configuration in a database or config layer.

## Unit economics

Track internally:
- model cost
- runtime cost
- integration cost
- storage
- operator time
- support time
- deployment time
- gross margin

Target the business toward a high proportion of recurring revenue while keeping fulfilment repeatable.

## Scope protection

Subscription does not mean unlimited bespoke engineering.

Every change request should have:
- type
- estimate
- priority
- approval
- status

Automate common requests; manually handle exceptional requests.
