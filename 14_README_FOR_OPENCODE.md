## First task

Do NOT build the entire application immediately.

First:
1. inspect repository
2. inspect docs
3. propose stack
4. propose architecture
5. identify open questions
6. produce implementation plan
7. implement Milestone 0
8. wait for validation before moving to Milestone 1 if running interactively

## Product principle

The customer buys a tailored AI employee.

The platform provides the machinery to:
- configure
- deploy
- monitor
- secure
- evaluate
- improve
- bill
- manage

## Development principle

Build reusable infrastructure and customer-specific configuration.

Avoid creating a bespoke application for each customer.

## Production principle

Reliability and security matter more than flashy demos.
